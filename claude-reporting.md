# Отчётность: одна карточка и одна диаграмма

Только `cmd/dashboard/static/terminal.html`. Сервер, поля API и расчёты не менять. Новый источник не подключать. Нет числа — пустая ячейка «нет», не ноль.

Образец: https://htmlpreview.github.io/?https://raw.githubusercontent.com/Foxtel95/terminal-maket/main/reporting-pro.html
Цифры на образце — снимок TATN, в код их не копировать. Брать `d.historyQuarterly` / `d.historyAnnual` и `d.card`.

## Экран

Шапка как сейчас: имя, сектор, вес IMOEX, бизнес, цена, капитализация. Под ней одна строка свежести из `repFreshHTML` (уже есть `card.fresh`).

Полоса из восьми чисел, каждый один раз: P/E, EV/EBITDA, ROE, чистая маржа, ND/EBITDA, дивдоходность 12 мес, оценка DPS, её доходность. Поля уже есть: `d.current` и `card.header`, `card.estimate`, `card.estYield`. Блок `repCurrent` ниже таблицы убрать, чтобы не повторять.

Две колонки. Слева таблица `repTable` и одна диаграмма. Справа: «Что изменилось» (`card.changes`), дивиденды (`repCardDiv`), факторы (`repCardFactors`). Проверки `card.checks`: сначала `flag`, потом `ok`. Строки `nodata` спрятать под «нечего проверить».

Кнопку «Проверить парсер» из шапки отчётности убрать. Обработчик не удалять.

Таблица. Периоды — `repList`. Если соседние подписи вида `2025Q2` и `2025Q4`, между ними колонка «нет», без числа. Иначе дыру не выдумывать. Процент «к году» — один столбец справа, тот же `repYoY` по последнему периоду. Второй строкой под каждым числом его не писать.

## Диаграмма

`repCardCharts` сейчас рисует четыре графика. Заменить одним. Второй график «Финансы, млрд ₽» в `repTable` (вызов `repChips('repFinSel'…)`) удалить. График мультипликаторов там же удалить: они уже в полосе.

Кнопки, по умолчанию включены только Выручка и Чистая прибыль:

| Кнопка | поле | цвет |
|---|---|---|
| Выручка | revenue | #58a6ff |
| EBITDA | ebitda | #a371f7 |
| Опер. прибыль | operProfit | #d29922 |
| Чистая прибыль | netProfit | #3fb950 |
| Чистая маржа | netMargin | #7ee787 |
| FCF | fcf | #39c5cf |
| Чистый долг | netDebt | #f85149 |
| Капитал | equity | #8b949e |
| Активы | assets | #6e7681 |

Нажатие добавляет или убирает ряд на этой же диаграмме. Рисует уже готовый `repSvg`: столбцы в млрд ₽, общая шкала, минус ниже нуля. `null` не рисовать.

Чистая маржа — проценты. Её не класть в шкалу миллиардов. Если кнопка включена, линия по правой шкале 0–40%. Под кнопками одна строка, всегда: «FCF — свободный денежный поток: деньги, которые остались после текущей работы и вложений в производство.»

Выбор кнопок помнить в `localStorage` ключом `repChartOn`. Чужие ключи графика не трогать.
