# График: список, свеча 460px, стакан. Реальное время

Сделать рабочим только вкладку «График». Остальные вкладки, сигналы, бота и риск не менять. Новый источник данных не подключать. Цены в браузер не выдумывать: нет ряда — пусто и текст причины.

Макет раскладки (не котировки): https://raw.githubusercontent.com/Foxtel95/terminal-maket/ee007e7/chart-column.png

## Что уже есть

- Свечи: `GET /api/v2/chart?ticker=&interval=` → `handleChartPro` → `cpLoadCandles`. День и неделя из `candleCache`. Минуты с ISS TQBR, кэш в `cpTimeframes`: `1` = 30 с, `10` = 60 с, `60` = 5 мин. Ответ уже содержит `candles`, `ind` (sma20/50/200), `ta`, `levels` (не больше 3+3), `signals`, `tickers`, `zone`, `poc`.
- Живая цена: `livePrice(ticker)` в `cmd/dashboard/livefeed.go`, стрим T-Invest уже крутится. `GET /api/live` цену не отдаёт, только статус. В браузерный сокет цену не выносить.
- Стакан: `marketdata.GetOrderBookImbalance` (`internal/marketdata/orderbook.go`), T-Invest `GetOrderBook`. Уровни `Bids`/`Asks`: `Price`, `Lots`. HTTP для графика нет. ISS-стакан не подключать.
- Рисование: `tabs.chart` в `cmd/dashboard/static/terminal.html`. Блок `#chBox` высотой 460px. Объём: своя шкала, `scaleMargins.top = 0.8`. Свечи: `bottom = 0.25`. Осциллятор `#chOsc` 170px. Меню слева уже есть, ширина `.sidebar` 232px.

## Экран

Только внутри вкладки «График», под существующим левым меню:

1. Колонка списка. Тикеры из поля `tickers` этого же ответа. Клик меняет бумагу и перерисовывает график. Поиск по тикеру оставить.
2. Свеча. Высота ровно 460px. Объём и отступы шкал не менять. Таймфреймы те же: 1м, 10м, 1ч, День, Неделя.
3. Стакан справа, 10 цен продажи сверху (лучшие у последней цены), 10 покупок снизу. Полоса — лоты. Под лестницей спред (лучшая продажа минус лучшая покупка), время кадра и источник `T-Invest`. Пусто или ошибка: текст «стакана нет», нули не рисовать.

В левое меню, сразу под кнопкой «График», две кнопки:

- «Индикаторы» раскрывает список, который сейчас в `#chInd`: SMA 20/50/200, EMA 9/21, Bollinger, Supertrend, VWAP ±σ, ATR, ADX/DMI, Stochastic, OBV, и пресеты «Тренд», «Внутри дня», «Разворот», плюс «Чисто». Ряд этих кнопок с графика убрать. Линии по-прежнему берутся из `ind` и `ta` ответа, в браузере не пересчитывать. ATR, ADX, Stochastic, OBV остаются на `#chOsc` (170px), не на свечах.
- «Уровни» включает и выключает уже пришедшие `levels`. Считать заново не надо.

По умолчанию оба выключены. Если в `localStorage` ключа ещё нет, график пустой: только свечи и объём. Если ключ уже сохранён пользователем, не затирать. Связать с уже существующим чекбоксом «Уровни на графике» в настройках: один ключ, не два независимых флажка. С `#chBox` снять атрибут, который включает уровни сам.

Клик по цене стакана копирует её (как уже копируются уровни) и ставит одну временную горизонтальную линию. Это не уровень и не сигнал.

## Реальное время

Пока открыта вкладка «График» и страница видима (`document.hidden === false`). Ушли с вкладки — таймеры снять.

- Свечи. Повтор `GET /api/v2/chart` только открытого тикера. Не чаще кэша ISS: 1м — 30 с, 10м — 60 с, 1ч — 5 мин, день и неделя — 60 с. Чаще бессмысленно: ответ тот же.
- Последняя цена. В ответ `/api/v2/chart` добавить поле `last` из `livePrice(ticker)`: цена и время, если `ok`. Если нет — поле не писать. Браузер между опросами свечей двигает только close последней свечи и последнюю точку объёма не трогает. Новую свечу из тика не собирать.
- Стакан. Новый `GET /api/v2/orderbook?ticker=VSEH&depth=10`. Внутри один вызов `GetOrderBookImbalance`. Ответ: `bids`, `asks` (цена и лоты, лучшие первыми), `spread`, `time` (RFC3339, Москва не обязательна, но время сервера обязательно), `source: "T-Invest"`. Опрос раз в 3 секунды, только эта бумага. Ошибка T-Invest — HTTP-ошибка с коротким текстом, интерфейс показывает «стакана нет». В выходные пустая книга нормальна.

Список. Для тикеров ответа, и только для них, можно добавить цену из `livePrice` и процент к предыдущему дневному закрытию из `candleCache`, если оба числа есть. Нет числа — тикер без процента.

## Не делать

- Второй стрим, сокет в браузер, ленту сделок, стакан ISS, стакан Algopack.
- Опрос всех тикеров рынка.
- Смену высоты 460 / 170 и логики сигналов на графике (вход, стоп, цель рисуются как сейчас, это не «уровни»).
- Включение индикаторов по умолчанию.
